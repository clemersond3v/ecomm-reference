# Definition of Done — Ecom Microservices Lab (Next.js + NestJS + AWS)

Uma funcionalidade/serviço é considerado “pronto” quando:
- Build e testes passam
- Documentação mínima atualizada (README + contratos se aplicável)
- Possui health checks (liveness/readiness)
- Logs estruturados e correlationId
- Rodando localmente via compose (ou k8s quando aplicável)
- Código revisável (lint/format ok)
